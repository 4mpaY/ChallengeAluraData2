Análisis de Cancelación de Clientes (Churn)

Este proyecto consiste en analizar los datos de clientes de una empresa de telecomunicaciones para entender por qué algunos clientes cancelan el servicio.

A lo largo del proyecto se trabajó con los datos para limpiarlos, analizarlos y luego entrenar algunos modelos simples de machine learning que intentan predecir si un cliente podría cancelar el servicio.

La idea principal es encontrar patrones en los datos y ver qué factores pueden estar relacionados con la cancelación de clientes.

Qué se hizo en el proyecto

Durante el desarrollo del proyecto se realizaron las siguientes etapas:

Carga y limpieza de los datos.

Eliminación de columnas que no aportaban al análisis.

Conversión de variables categóricas a formato numérico.

Exploración de los datos con gráficos para entender mejor los patrones.

Balanceo de datos usando SMOTE.

División de los datos en entrenamiento y prueba.

Creación de dos modelos de predicción:

Regresión Logística

Random Forest

Evaluación de los modelos utilizando diferentes métricas.

Objetivo

El objetivo del proyecto es practicar el proceso completo de análisis de datos y construcción de modelos simples de machine learning para entender el problema de cancelación de clientes.
